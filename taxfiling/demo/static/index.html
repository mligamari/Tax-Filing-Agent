W-2 Filing Agent

Turns a W-2 spreadsheet into the fixed-width text file a state wage-reporting portal accepts, then re-reads the file to prove it matches.

  • Runs on this computer
  • SSNs never sent to AI
  • Synthetic data only
  1. Spreadsheet
  2. Column mapping
  3. Output
  4. Checked file

1 Choose a spreadsheet

Drop in a W-2 workbook, or start with one of the synthetic samples. Every person and company in the samples is made up.

2 Map the columns

Every payroll system names its columns differently. The agent proposes which column holds which W-2 box. You review it before anything is written.

What the AI would see

This is the complete message a model receives. Values are replaced by their shape: 123-45-6789 becomes ###-##-####, a name becomes Aa Aa. Before sending, the program checks this text, and the request itself, against every cell in the workbook, and refuses to send if any value appears.
